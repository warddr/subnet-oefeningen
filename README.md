# subnet-oefeningen
html / js subnet oefeningen

- `index.html` – overzicht van alle oefeningen
- `nwbroadcasthosts.html` – netwerkadres, broadcastadres, eerste/laatste host en aantal hosts
- `zelfdesubnet.html` – waar/niet waar: liggen twee IP-adressen in hetzelfde subnet?
- `cidrmasker.html` – CIDR ↔ subnetmasker omzetten (beide richtingen)
- `ipv6.html` – IPv6-adres zo kort mogelijk schrijven, of voluit schrijven

`common.css` en `common.js` worden door alle pagina's gedeeld.
